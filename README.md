# بناء النماذج الأولية لمنتجات الذكاء الاصطناعي باستخدام وكلاء البرمجة

Prototyping AI Products with Coding Agents

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-PRD-205 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يوجّه العاملون في المنتجات والتصميم وكيل برمجة لبناء نموذج أولي لتطبيق ويب يستدعي نموذجًا مستضافًا على بيانات اصطناعية، ثم يضيفون فحوصات القبول، ويختبرونه مع خمسة مستخدمين، ويحددون المواضع التي تضلل فيها النماذج الأولية التي يبنيها الوكلاء، ويسلّمون الفريق الهندسي ما يُحتفظ به وما يُستبعد. أما الأدوات التي لا تحتاج إلى برمجة فيغطيها المقرر USE-FLU-205، والهندسة باستخدام الوكلاء يغطيها المقرر DEV-SWE-201.

**الصيغة:** ورشة عمل: يومان مع مختبرات وعمل تحضيري موجه واختبار مع خمسة مستخدمين

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-prd-205/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يعدّ موجزًا وملف سياق يحددان السؤال والنطاق والبيانات والقيود ومعايير الإنجاز، استنادًا إلى فكرة الحالة ومواصفاتها | Applied | موجز يبني الوكيل منه نسخة أولى عاملة |
| LO2 | يستخدم وكيل برمجة لبناء نموذج أولي يستدعي نموذجًا لغويًا، بخطوات صغيرة متحقق منها وتحت إدارة الإصدارات، باستخدام بيئة عمل معزولة ومفتاح محدود الإنفاق وبيانات اصطناعية | Applied | نموذج أولي يعمل وإيداع لكل خطوة عاملة |
| LO3 | يختبر النموذج الأولي وفق فحوصات القبول وقائمة تحقق للحدود تشمل المسارات المضمّنة في الرموز البرمجية والأسرار المكشوفة والتبعيات غير المفحوصة والبيانات الحقيقية وإمكانية الوصول، على النموذج الأولي العامل | Applied | سجل فحوصات وقائمة حدود مرتبة |
| LO4 | يسلّم حزمة تسليم تفصل ما ثبت من تعلّم والمواصفات وحالات التقييم عن الرموز البرمجية الواجب استبعادها، استنادًا إلى نتائج الاختبار مع خمسة مستخدمين ومراجع هندسي | Performance | حزمة تسليم تُقبل في مراجعة مباشرة |
