# بناء النماذج الأولية لمنتجات الذكاء الاصطناعي باستخدام وكلاء البرمجة: المختبرات

مختبرات مقرر أكاديمية سدايا **LDS-PRD-205**. كل مختبر صفحة تُفتح من صفحة المقرر، وكلها على نموذج أولي واحد: **«شارح تغيير الحجز»** في طيران قُبّرة، وهو ناقل افتراضي. كل مختبر يبدأ من حالة مرجعية جاهزة، وآخر خطوة فيه لفكرة المشارك نفسه.

النموذج الأولي يعمل على حاسوب محمول عادي، بمكتبة Python القياسية وحدها. يستدعي نموذجًا مستضافًا بمفتاح محدود الإنفاق، أو يعمل ببديل مكتوب مسبقًا لا يحتاج إلى مفتاح. لا يُنزَّل أي نموذج على الجهاز.

## ما يلزم على جهاز المشارك

1. مساحة عمل معزولة فيها `git` و`uv` (حاوية تطوير محلية، أو بيئة تطوير مستضافة بباقة مجانية).
2. وكيل برمجة، مثل goose أو OpenCode أو وكيل تجاري تعتمده الجهة، مضبوط على أن يسأل قبل أي أمر أو تعديل.
3. مفتاح لنموذج مستضاف بحد إنفاق ولمدة الورشة، يوزعه المدرب. يوضع في `.env` فقط.

التحقق، وهو جزء من العمل التحضيري ([`files/prework_guide.md`](files/prework_guide.md)): فك `files/kit/v2.zip`، ثم داخل المجلد:

```
uv run app.py
```

افتح العنوان المطبوع، واكتب `QB4K7M`. توقفه بالضغط على Ctrl+C.

## حالات النموذج الأولي

| الحالة | ما فيها | الفحوصات الخمسة |
|---|---|---|
| `start` | البيانات فقط: القواعد وستة حجوزات للعرض | لا ينطبق |
| `v1_step1` إلى `v1_step3` | الصفحة؛ ثم البحث عن الحجز؛ ثم القاعدة والرسوم | لا ينطبق |
| `v1_broken` | الخطوة 3 بعد «ترتيب» لم يُطلب كسر البحث | لا ينطبق |
| `v2` | الشرح بالنموذج، والمفتاح في `.env`، وحد للاستدعاءات، و40 حجزًا | 3 من 5 |
| `v3` | بعد إصلاح ما كشفته الفحوصات، ومعه `checks.py` | 5 من 5 |
| `seeded` | v3 بعد «آخر يوم قبل العرض»، وفيه حدود مزروعة عمدًا. للمختبر 2.2 فقط | 4 من 5 |

أوضاع النموذج في `.env`: `MODEL_MODE=stub` (البديل المكتوب مسبقًا، الافتراضي)، و`hosted` (نموذج مستضاف بالعنوان والاسم والمفتاح في `.env`)، و`fail` (لتجربة التعطل). `MODEL_MAX_CALLS` حد الاستدعاءات.

## للمدرب: التحقق من الحلول

```
uv run labs/_tools/prepare_files.py
uv run labs/solutions/run_all.py
```

الأول يكتب البيانات والملفات المضغوطة من مصدر واحد، بالنتيجة نفسها في كل تشغيل. الثاني يشغّل حل كل مختبر ويطبع PASS: المختبر 1.3 ينشئ مستودع Git مؤقتًا ويودع الخطوات ويتراجع عن التغيير المكسور. لا يُستدعى أي نموذج مستضاف ولا يلزم مفتاح: حيث يوجّه المشارك وكيل برمجة، تمثّل الحالات المرجعية رد الوكيل، وحيث يُستدعى النموذج يعمل البديل المكتوب مسبقًا.

## حدود النموذج الأولي

«شارح تغيير الحجز» نموذج أولي للتدريب: يعمل على جهاز واحد، على بيانات اصطناعية، ولا يغيّر أي حجز، ولم يراجع شيفرته مهندس. قواعد الأجرة فيه قواعد الحالة الافتراضية. هذه الحدود نفسها ما يكتبه المشارك في حزمة التسليم.
