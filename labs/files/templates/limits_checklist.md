# قائمة تحقق الحدود

لكل بند: موجود أم لا، وأين (الملف والسطر أو الشاشة)، والأثر إن وصل النموذج الأولي إلى مستخدم حقيقي.
الأثر: 3 يمنع أي عرض على مستخدمين، 2 يُصلح قبل الاختبار، 1 يُكتب في التسليم.

| # | البند | كيف تفحصه | موجود؟ | أين | الأثر |
|---|---|---|---|---|---|
| 1 | سر مكتوب في ملف (مفتاح، كلمة سر، رمز) | الفحص الآلي، ثم ملفات المتصفح | | | |
| 2 | مسار على جهاز شخص واحد | الفحص الآلي | | | |
| 3 | حزمة لم تُفحص (ضرورتها، صيانتها، ترخيصها، إصدار مثبت) | الفحص الآلي، ثم صفحة الحزمة | | | |
| 4 | بيانات حقيقية أو تشبه الحقيقية | الفحص الآلي، ثم مصدر كل ملف بيانات | | | |
| 5 | لغة الصفحة واتجاهها (`lang`، `dir`) | عرض المصدر | | | |
| 6 | عنوان لكل حقل، وتباين النص، والعمل بلوحة المفاتيح | باليد | | | |
| 7 | ترخيص كل صورة وخط وأيقونة ونص مولَّد | مصدر كل أصل وشروطه | | | |
| 8 | إفصاح أن الذكاء الاصطناعي مستخدم، على الشاشة وللمختبِرين | باليد، ونص الموافقة | | | |

## القائمة المرتبة
رتّب ما وجدته: الأثر أولًا، ثم سهولة الإصلاح. سطر لكل بند: البند، والأثر، والإصلاح، ومن يصلحه.
